# 프로젝트 생성 CLI

저장소 루트에서 `pnpm new --help`로 단독·조합 생성 명령을 확인한다.

CLI 위치가 git 저장소 루트와 맞아야 한다. Windows에서는 드라이브 문자나 폴더 이름의 대소문자가 달라도 같은 위치로 인정한다. 다른 폴더 구조에서 실행하면 배치 오류로 거절한다.

실패는 `pnpm new: <문제> — <고치는 방법>` 한 줄로 알린다. 문제에는 시스템 오류 코드와 경로, 일반 오류 이름과 원인, git stderr의 첫 줄, 또는 잘못 지정한 옵션의 원인을 포함한다. 잘못된 이름을 포함한 사용법 오류는 종료 코드 2, 그 밖의 오류는 1이다.

git 사용자 정보가 없으면 저장소만 초기화하고 `user.name`·`user.email` 설정과 첫 커밋 방법을 안내한다.

첫 커밋은 복사한 템플릿 파일을 이름 목록으로 강제 추가한다. 사용자의 전역 excludes가 `.env.example`, `.claude/`, `.mcp.json`을 무시해도 해당 파일을 빠뜨리지 않는다. 조합에서 새로 만든 파일도 프로젝트의 ignore 규칙에 따라 추가하며 설치물과 캐시는 포함하지 않는다.
