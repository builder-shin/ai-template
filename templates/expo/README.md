# Expo mobile template

Native iOS and Android app sharing the platform JSON:API contract.

```text
pnpm setup
pnpm dev
pnpm check
pnpm export --platform android
```

Use a development build for authentication. See [authentication](docs/recipes/authentication.md), [development](docs/recipes/development.md), [stack](docs/stack.md), and [AGENTS.md](AGENTS.md). Native builds need the platform SDK; an exported JS bundle does not prove a native build or device flow.
