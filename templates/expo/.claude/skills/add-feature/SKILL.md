Read [the feature recipe](../../../docs/recipes/add-feature.md) from the project root before using `pnpm gen:feature <lower-kebab-name>`. It defines the posts golden, generated paths and required API/permission/language review. The scaffold keeps the posts contract until that review is implemented. Run the recipe's checks and native flows for the resulting resource.
