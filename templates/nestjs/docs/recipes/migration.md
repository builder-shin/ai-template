# 마이그레이션

DB 명령과 Prisma 스키마는 Task 3에서 구현한다. 현재 `db:migrate`·`db:reset`·`db:revision`은 Task 안내와 종료 코드 1을 반환한다.

스키마 변경 뒤에는 DB 없이 이전 스키마와 새 스키마의 차이로 SQL 초안을 만든다.
첫 마이그레이션은 빈 스키마부터 시작하며 이후에는 직전 커밋의 스키마를 입력으로 쓴다.
SQL을 검토해 UTC 시각과 이름을 붙인 migrations 폴더에 기록하고 새 일반 커밋으로 남긴다.
적용된 마이그레이션은 수정·삭제하지 않는다. 적용과 drift 검증은 준비된 CI 환경에서 수행한다.
